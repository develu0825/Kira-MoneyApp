# CODEF 가입 & 무료 티어 확인 체크리스트

> 목표: 돈 들이기 전에 "내가 쓸 범위(카뱅 하나, 하루 1번)가 무료/저비용으로 되는지"를
> 가장 빨리 확인한다. 공개 요금표가 없어서 **콘솔에서 직접 확인 + 문의**가 핵심이다.

## 0. 사전 정보 (조사로 확인된 사실)

- 지원: 카카오뱅크 `0090`, 토스뱅크 `0092`, 신한 `0088` 모두 지원.
- 카뱅/토스는 **간편인증(폰 승인)** 방식. 아이디/비번 웹로그인 없음.
- 요금: **정액 요금표 비공개**, 사용 데이터·호출량 기준 **견적/상담제**.
- 무료(데모) 버전으로 **실제 금융기관 계정 붙여서 테스트/구축 가능**. 개인 가입 가능.
- ⚠️ 무료 티어의 **정확한 호출 한도는 공개 수치 미확인** → 아래에서 직접 확인.

## 1. 회원가입 / 서비스 등록

- [ ] https://codef.io 가입 (개인 가능)
- [ ] 콘솔에서 **서비스(앱) 생성**
- [ ] **클라이언트 ID / Secret** 발급 (DEMO용, 정식용 2종 확인)
- [ ] **RSA Public Key** 발급/다운로드
- [ ] 발급값을 환경변수로 저장 (앱·git에 커밋 금지)
  ```bash
  export CODEF_CLIENT_ID=...
  export CODEF_CLIENT_SECRET=...
  export CODEF_PUBLIC_KEY=...
  ```

## 2. 무료/과금 조건 확인 (가장 중요)

- [ ] 콘솔 내 **요금/과금(Pricing·Usage) 메뉴**에서 다음을 확인:
  - [ ] DEMO 버전 **월/일 호출 가능 횟수** (예: 하루/월 N회)
  - [ ] DEMO ↔ 정식 **기능 차이** (조회 가능 기관/기간 제한 여부)
  - [ ] 정식 전환 시 **과금 단위** (호출당 / 월 구독 / 기관별)
  - [ ] **개인 명의로 정식 전환 가능 여부** (사업자 필요한지)
- [ ] 안 나오면 **문의/상담 폼으로 질문** (아래 템플릿)

### 문의 템플릿
```
개인 용도로 제 명의 계좌(카카오뱅크 1개)의 수시입출 거래내역을
하루 1회 조회하려 합니다.
1) 이 사용량이 무료(데모) 범위로 가능한가요?
2) 데모의 일/월 호출 한도는 몇 회인가요?
3) 초과 시 정식 전환 비용(개인 기준)은 어떻게 되나요?
4) 개인 명의로도 정식 사용이 가능한가요(사업자 필요 여부)?
```

## 3. DEMO로 동작 검증 (돈 쓰기 전)

- [ ] `python -m pip install easycodefpy`
- [ ] `collector/codef_collector.py`의 CONFIG 채우기
  - [ ] `USE_DEMO = True`
  - [ ] `KAKAO_ACCOUNT`, `MY_NAME`, `MY_BIRTH`, `MY_PHONE` 환경변수 설정
  - [ ] 간편인증 파라미터(`loginType`,`loginTypeLevel`)를 **카뱅 문서값으로 보정**
  - [ ] `TRANSACTION_URL`과 응답 필드 매핑을 **문서 스펙으로 보정**
- [ ] 실행 → 폰으로 간편인증 승인 → `money.db`에 거래 저장되는지 확인
- [ ] `money.db` 열어서 `counterparty`, 금액, `is_self_transfer` 자동감지 확인

## 4. 자동화 (검증 후)

- [ ] 맥/라즈베리파이 **cron**에 하루 1회 등록 (예: 매일 08:00)
  ```bash
  0 8 * * * cd /path/money/collector && python codef_collector.py >> run.log 2>&1
  ```
- [ ] ⚠️ 카뱅 간편인증은 **ConnectedId 만료 시 폰 재승인 필요** → 완전 무인 아님.
      → cron 실패 로그 모니터링 + "재인증 필요" 알림 고려
